# Logiciel de Gestion de Base de Pompiers

## Description
Ce projet est une application Windows Forms en **C#** qui permet de gérer une base de données de pompiers.  
L'application facilite le suivi des informations des pompiers, des interventions, des équipes et du matériel.

---

## Fonctionnalités
- Gestion des pompiers (ajout, modification, suppression)  
- Suivi des interventions et des incidents  
- Gestion des équipes et des plannings  
- Suivi du matériel et des équipements  
- Interface utilisateur intuitive avec Windows Forms  

---

## Technologies
- **Langage :** C#  
- **Framework :** .NET (Windows Forms)  
- **Base de données :** SQLite / SQL Server (selon configuration)  
- **IDE recommandé :** Visual Studio
